# Card Game ZhaJinHua

基于 MATLAB 实现的炸金花（扎金花）命令行小游戏。

## 项目简介

本项目使用 MATLAB 模拟经典扑克牌游戏“炸金花”的基本流程，实现了随机发牌、牌型判断、胜负比较和结果输出等功能。程序通过命令行与用户交互，输入玩家人数和游戏轮数后，即可自动完成多轮发牌与比牌，并输出每轮的游戏结果。

该项目适合作为 MATLAB 课程设计、程序设计练习或简单游戏逻辑实现案例。

## 功能说明

本项目主要实现了以下功能：

- 支持输入玩家人数
- 支持多轮游戏模拟
- 随机从一副 52 张扑克牌中发牌
- 自动判断每位玩家的牌型
- 自动比较牌面大小并给出获胜者
- 在命令行中输出每位玩家的手牌、牌型和最终赢家

## 牌型规则

程序中实现的牌型包括：

- 单张
- 对子
- 顺子
- 金花
- 同花顺
- 豹子

其中牌型等级由低到高依次比较；若牌型相同，则继续比较点数大小，必要时比较花色。

## 文件结构

- `main.m`：主程序入口，负责用户输入、控制游戏轮数和整体流程
- `cutCard.m`：随机发牌
- `dispCard.m`：输出每位玩家的手牌与牌型信息
- `calCardStyle.m`：计算并判断牌型
- `giveWinner.m`：比较所有玩家手牌并给出赢家
- `num2card.m`：将数字形式的牌转换为可读的扑克牌表示

## 运行环境

- MATLAB

## 使用方法

1. 将所有 `.m` 文件放在同一目录下
2. 在 MATLAB 中打开该项目文件夹
3. 运行主程序：

   `main`

4. 按提示输入：
   - 玩家人数
   - 游戏轮数

程序会自动输出每轮游戏中各玩家的手牌、牌型和获胜者。

## 示例说明

运行后，程序会先要求输入玩家人数。由于一副牌共有 52 张、每位玩家发 3 张，因此程序对人数做了限制，通常支持 2 到 17 人参与。

每轮游戏中，程序会：

1. 随机生成每位玩家的三张手牌
2. 将数字牌转换为具体牌面
3. 识别每位玩家的牌型
4. 自动比较大小并输出胜者

## 项目特点

- 采用模块化函数设计，结构较清晰
- 实现了完整的发牌、判型、比牌流程
- 适合用于练习随机过程模拟与规则判断
- 体现了 MATLAB 在小游戏逻辑实现中的基础应用

## 局限性说明

- 当前项目为命令行版本，不包含图形界面
- 主要实现基础炸金花规则，未加入下注、跟注、弃牌等更完整的博弈机制
- 牌型比较规则基于当前程序设定，若要严格对齐不同地区或平台规则，还可继续扩展
- 项目更偏向程序逻辑练习与规则模拟，不涉及联网、AI 对战或复杂交互设计

## 说明

本项目为学习与练习用途，重点在于扑克牌规则建模、随机发牌与比较逻辑的实现。
